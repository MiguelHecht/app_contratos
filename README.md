## 📌 Sobre o Projeto

O **Albert** é uma ferramenta desenvolvida para otimizar e padronizar o processo de geração de contratos na empresa. O objetivo principal do projeto é reduzir o tempo gasto no preenchimento manual de formulários, eliminar erros operacionais e garantir conformidade com os padrões jurídicos da organização.

 Com o Albert, o que antes levava horas para ser elaborado manual e individualmente agora pode ser gerado em poucos minutos ou cliques.

---

## ✨ Funcionalidades Principais

- ⚡ **Geração Rápida:** Criação de contratos completos a partir de formulários simples ou inserção de dados via API.
- 📋 **Modelos Dinâmicos (Templates):** Suporte a múltiplos tipos de contratos com cláusulas pré-configuradas e variáveis dinâmicas.
- 🔍 **Validação de Dados:** Checagem automática de campos obrigatórios (CPF/CNPJ, endereços, valores) antes da emissão.
- 📄 **Exportação Multiformato:** Exportação direta para PDF e Word (`.docx`).
- 🔐 **Segurança e Conformidade:** Garantia de integridade das cláusulas padrão aprovadas pelo departamento jurídico.
